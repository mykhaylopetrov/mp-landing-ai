# TaskFlow AI — лендінг

> Весь код і дизайн цього проєкту створено за допомогою AI.

Статичний багатосторінковий лендінг вигаданого SaaS-продукту **TaskFlow AI** —
«розумного менеджера завдань зі штучним інтелектом» (українською мовою).
Чистий HTML + CSS + vanilla JS, без збірки та бекенда. Залежності (Swiper, GLightbox)
лежать локально в `vendor/`, CDN не потрібен.

## Структура проєкту

| Файл / папка | Призначення |
|---|---|
| `index.html` | Головна сторінка (усі секції лендінгу) |
| `blog.html` | Список статей блогу + сайдбар |
| `single-blog.html` | Сторінка однієї статті |
| `privacy.html` | Політика конфіденційності |
| `styles.css` | Усі стилі (дизайн-токени, секції, адаптив, темна тема) |
| `script.js` | Уся інтерактивність головної (див. нижче) |
| `gallery.js` | Ініціалізація GLightbox для галереї |
| `vendor/swiper/` | Локальна копія Swiper (слайдер відгуків) |
| `vendor/glightbox/` | Локальна копія GLightbox (лайтбокс галереї) |
| `images/` | Локальні SVG (`gallery-*.svg`, `priority-dashboard.svg`) |

## Сторінки та секції головної

1. **Header** — логотип, навігація (Можливості, Як?, Roadmap, Тарифи, Відгуки, Історії, Галерея, FAQ, Контакти, Блог), перемикач теми, бургер-меню. Посилання на блок табів у меню **навмисно немає**.
2. **Hero** — заголовок, CTA, демо-модалка, візуальні картки спринту.
3. **Logos** — «Нам довіряють 12 000+ команд».
4. **Features** (`#features`) — 6 карток можливостей.
5. **Showcase — «Продукт у дії»** (`#showcase`) — блок із табами та картками з фото (детальніше нижче).
6. **How** (`#how`) — 3 кроки.
7. **Stats** — анімовані лічильники.
8. **Roadmap** (`#roadmap`) — вертикальний таймлайн зі stagger-reveal.
9. **Pricing** (`#pricing`) — 3 тарифи.
10. **Testimonials** (`#testimonials`) — сітка відгуків.
11. **Stories** (`#stories`) — слайдер Swiper (3/2/1 слайд).
12. **Gallery** (`#gallery`) — CSS-masonry з `picsum.photos` + GLightbox.
13. **Blog preview** (`#blog`) — 3 останні статті.
14. **FAQ** (`#faq`) — акордеон (`<details>`).
15. **Contacts** (`#contacts`) — картки контактів + форма з валідацією.
16. **CTA** (`#cta`) — форма email.
17. **Footer**, кнопка «Нагору», прогрес-бар скролу, модалка «Замовити демо».

## Блок із табами (`#showcase`)

Гарний блок вкладок із фотографіями (`https://picsum.photos`).
Таби: **Усі · Аналітика · Команда · AI-асистент**.

- Перший таб **«Усі»** містить усі 14 карток з інших табів.
- Решта табів — підмножини з різною кількістю та різним змістом:
  - Аналітика — 2 картки (Velocity, Burndown);
  - Команда — 4 картки (Ролі, Синки, Ретро, Онбординг);
  - AI-асистент — 5 карток (Підказки, Тексти, Голос, Прогноз, Звіти).
- Кожна картка: фото (landscape `600/450`), тег-бейдж, заголовок, короткий текст.
- Сітка карток **однакова в усіх табах** незалежно від кількості:
  3 колонки (десктоп) → 2 (планшет ≤860px) → 1 (мобільний ≤640px),
  відступи `gap` / `row-gap` 24px (20px на мобільному) — вертикальний ритм між рядами.
- Доступність: `role="tablist/tab/tabpanel"`, `aria-selected/aria-controls`,
  керування з клавіатури (←/→, Home/End), анімація появи панелі.

## JavaScript (`script.js`)

Весь код — один IIFE без залежностей:

- повільний rAF smooth-scroll за якірними посиланнями + прогрес-бар;
- бургер-меню (`html.menu-open`), закриття по Esc/кліку повз;
- світла/темна тема (`data-theme`, `localStorage`, `theme-color`);
- кнопка «Нагору» з 5-секундним скролом;
- тінь хедера при скролі;
- анімовані лічильники (IntersectionObserver);
- FAQ-акордеон (один відкритий елемент);
- валідація CTA / демо / контактної форм (фейковий сабміт);
- Swiper-слайдер «Історії»;
- reveal анімація таймлайну;
- модалка з фокус-пасткою та поверненням фокусу;
- **таби showcase** (див. вище).

## Стилі (`styles.css`)

- CSS-змінні (токени кольорів, радіуси, тіні) + `[data-theme="dark"]` перевизначення;
- mobile-first, брейкпоїнти 1100 / 1024 / 900 / 860 / 768 / 640 / 380px;
- Flexbox/Grid, без float; `scroll-margin-top` під фіксований хедер;
- `prefers-reduced-motion` підтримується.
